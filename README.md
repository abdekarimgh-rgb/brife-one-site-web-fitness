# Elan Fitness:
Élan Fitness est un projet de refonte d'un site web de fitness. L'objectif est de transformer un site one-page en un site multipage afin d'améliorer l'expérience utilisateur,
## Presentation:

1 - Ameliorer l'experience utilisateur (UX).
2 - Creer une interface moderne et attractive (UI).
3 - transforme le site a one page to multup pages
4 - Adapter le site aux ordinateurs, tablettes et telephones.

## Pages du site:

 _Accueil : presentation de la salles.
 _Programmes : presentation des cours et des formules.
 _À propos : histoire, valeurs et equipe d'Elan Fitness.
 _Contactez-nous : formulaire de contact et coordonnees.
 _login : page motivation pour l'inscreption ou salles

 ##  Technologies utilisees:
